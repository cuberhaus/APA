# APA

Problem sets and assignments for the APA (Algorítmica i Programació Avançada / Advanced Pattern Analysis) course at FIB-UPC.

## Overview

Covers a range of machine learning and statistical topics through five problem sets, including Kullback-Leibler divergence, regression on real-world datasets, neural networks on MNIST, Bayesian models, and more.

## Structure

```
├── Problema1/    # Kullback-Leibler divergence and probability distributions
├── Problema2/    # Regression: Bike-Sharing, BCMB, IBEX35 datasets
├── Problema3/    # Neural networks on MNIST
├── Problema4/    # Bayesian models
└── Problema5/    # Prediction tasks (Lista de la compra)
```

Each problem folder contains Jupyter notebooks (`.ipynb`) and supporting Python scripts.

## Tech Stack

- **Python** with JAX, NumPy, SciPy, scikit-learn, matplotlib
- **Jupyter Notebooks** for analysis and visualization

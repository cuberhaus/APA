# Security Policy — APA

## Reporting a Vulnerability
If you discover a security vulnerability, please email polcg10@gmail.com. Do not open a public issue.

## Security Considerations
- This repository contains ML problem sets (Python, JAX, Jupyter notebooks) for an academic course.
- All computation is local — there are no network calls, APIs, or web services.
- No sensitive data is stored; datasets are synthetic or publicly available.
- Not intended for production use.
